Docker Fullstack App

Aplicación Fullstack containerizada con Docker.

Tecnologías Usadas
- Backend:Node.js + Express (Puerto 3000)
- Frontend: HTML + JS servido con NGINX (Puerto 80)
- Orquestación: Docker

 Cómo ejecutar?
1. Clona el repositorio.
2. Construye las imágenes: Luego de haber ejecutado los comandos seguidos,se hacen los comandos de los contenedores y listo!
   ```bash
   docker build -t mi-backend ./backend
   docker build -t mi-frontend ./frontend
